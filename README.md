# DZ-14 — тестування Wi-Fi та BLE

Цей проєкт перевіряє дві **окремі** прошивки ESP32-S3 за вимогами `PRD.md` із матеріалів домашнього завдання. На платі одночасно може працювати лише одна з них.

## Обладнання та залежності

- ESP32-S3 DevKit, USB-кабель і Python 3.10+.
- Прошивки `station_WiFi_merged.bin` та `Bluedroid_GATT_Server_merged.bin` із `fw_4/git1`.
- Для BLE-перевірок — смартфон із nRF Connect.

Створіть віртуальне середовище й установіть залежності:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Драйвер автоматично шукає UART-порт за VID `1A86` і працює на швидкості `115200`. Якщо ваш USB-UART має інший VID, задайте `UART_VID` як шістнадцяткове число перед запуском тестів.

## Порядок роботи з прошивками

1. Очистіть флеш-пам'ять (`erase-flash`) і прошийте `station_WiFi_merged.bin` за адресою `0x0`.
2. Виконайте всі Wi-Fi тести Частини A та занесіть результати до `REPORT.md`.
3. Лише після завершення Частини A знову виконайте `erase-flash`, прошийте `Bluedroid_GATT_Server_merged.bin` за адресою `0x0` і переходьте до Частини B.

Очищення флеш-пам'яті перед кожною прошивкою потрібне, щоб у NVS не лишилися дані попередньої прошивки. Повні команди прошивання наведені в README відповідних папок із прошивками.

## Тестова Wi-Fi мережа

Для Частини A використовуйте мережу, якою керуєте. У цьому проєкті використовується хотспот iPhone: увімкніть «Максимальна сумісність» (`Maximize Compatibility`), щоб ESP32-S3 бачила мережу 2,4 ГГц.

Для параметризованих негативних тестів задайте пароль хотспота в такому форматі:

1. Рівно 9 цифр (`0–9`).
2. Один звичайний пробіл.
3. Одна мала латинська літера (`a–z`).
4. Одна велика латинська літера (`A–Z`).

Шаблон: `^[0-9]{9} [a-z][A-Z]$` (усього 12 символів). Це **передумова тестових даних**, потрібна для перевірок пробілів і регістру; це не загальна вимога прошивки до Wi-Fi паролів.

Не записуйте справжній пароль у код, README, скріншоти чи репозиторій. У терміналі, з якого запускаєте `pytest`, виконайте:

```bash
export WIFI_SSID='назва вашого хотспота'
read -r -s WIFI_PASSWORD
export WIFI_PASSWORD
```

Після `read` введіть повний пароль і натисніть Enter. Символи на екрані не відображатимуться. Після зміни пароля хотспота або відкриття нового термінала задайте `WIFI_PASSWORD` знову.

## Запуск тестів

Перед запуском закрийте інші програми, які використовують UART-порт плати. Для Wi-Fi-прошивки запускайте всю Частину A:

```bash
python -m pytest tests/wifi -v
```

Для BLE-прошивки після її встановлення запускайте окремо:

```bash
python -m pytest tests/ble/test_ble_smoke.py -v
```

Групи тестів запускаються окремо, оскільки потребують різних прошивок. Драйвер передається в тести через фікстури в `conftest.py`; `disconnected_device` перезавантажує Wi-Fi-плату перед тестом, щоб почати з відключеного стану.

Фактичні результати прогонів, докази й баг-репорти заносьте до `REPORT.md`. Перед додаванням скріншотів і логів перевіряйте, що в них немає пароля.
